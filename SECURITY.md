# Security policy

Evidence Bench walks a **fictional** small shop through CMMC Level 1 (Self) then Level 2 (Self). It is not a SPRS submission and not a C3PAO product.

- Do not put real CUI, customer inventories, or live SPRS scores in this repository.
- Harbor Precision and other sample names are fiction. Keep them that way.
- Assessment data you generate locally stays gitignored.

## Reporting

Open a GitHub issue on [rpsloss/evidence-bench](https://github.com/rpsloss/evidence-bench) for defects in the tool itself.

Do **not** paste live secrets, customer evidence, or CUI into issues.
